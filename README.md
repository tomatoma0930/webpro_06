# Webプログラミング 第7〜9回

授業で指定された [webpro_06](https://github.com/sudahiroshi/webpro_06) の `app5.js` が土台です。

このフォルダで `npm ci`、続けて `npm start` を実行し、ブラウザで [トップページ](http://127.0.0.1:8080/public/index.html) を開きます。終了は Control + C です。

| 回 | 確認する内容 | 主なページ |
| --- | --- | --- |
| 第6回 | InternetとWebの歴史。今回の実装に必要な個別課題は資料に記載なし | |
| 第7回 | 元のじゃんけんを残し、ラジオボタン版を追加 | `/public/janken2.html` |
| 第8回 | 京葉線の駅と、自由課題のポケモン図鑑を一覧表示・追加 | `/keiyo`、`/pokemon` |
| 第9回 | 京葉線の駅一覧から詳細を開き、詳細付きデータも追加 | `/keiyo2`、`/public/keiyo2_add.html` |

第8回と第9回の京葉線データは、資料と同じように別々の配列に入れています。追加したデータはサーバを停止すると消えます。

第7回の記述問題と第8〜9回の操作・仕組みは [演習の説明](演習の説明.md) にまとめています。レポート用の3題材の設計は [第9回の設計書](第9回_設計書.md) を参照してください。

ポケモン図鑑の初期データは全国図鑑No.0001〜0009の9体です。「ポケモンを追加」で登録を練習でき、一覧から追加したデータの詳細も開けます。初期データの出典は [ポケモンずかん](https://zukan.pokemon.co.jp/) です。
