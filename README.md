# Webプログラミング 第7〜10回

Node.js、Express、EJSを使った授業演習です。フォームから値を受け取るじゃんけんから始め、京葉線の駅一覧とポケモン図鑑で、データの一覧表示・詳細表示・登録・更新・削除まで実装しました。

## 起動方法

Node.jsとnpmを用意し、`package.json` があるフォルダで以下を実行します。

```sh
npm ci
npm start
```

起動したら、ブラウザで [トップページ](http://127.0.0.1:8080/public/index.html) を開きます。終了するときは、起動したターミナルで **Ctrl+C** を押します。

## 操作方法

- **じゃんけん** — [ラジオボタン版](http://127.0.0.1:8080/public/janken2.html)で手を選び、送信すると勝敗と対戦成績が表示されます。
- **京葉線の駅一覧** — [第8回の一覧](http://127.0.0.1:8080/keiyo?view=table)で駅を表示・追加できます。[第9〜10回の一覧](http://127.0.0.1:8080/keiyo2)では、駅名を選ぶと詳細が開きます。2つの一覧はそれぞれ別のデータを使います。
- **ポケモン図鑑** — [一覧](http://127.0.0.1:8080/pokemon)で図鑑番号・名前・タイプを確認できます。名前を選ぶと詳細が開きます。

第10回の2つのアプリでは、一覧の「追加」リンクから登録できます。詳細画面の「編集」から変更内容を保存し、「削除」から確認後にデータを削除できます。登録・更新・削除が完了すると一覧に戻ります。データはサーバ起動中に配列で管理し、再起動すると初期データに戻ります。
